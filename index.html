探索小指南

移動：點地圖上的島，或使用下方五個島嶼按鈕；鍵盤 Tab 也能操作。

觀看：拖曳地圖旋轉、滾輪縮放；觸控可單指旋轉、雙指縮放。點「回到全景」復原視角。

音樂：預設關閉。開啟後播放柔和合成音，可隨時關閉。

低刺激：停止轉場、淡化裝飾，並關閉音樂；島嶼與活動仍可操作。

課堂：先輸入課堂代碼與學號。重新整理會恢復同一瀏覽器的登入與進度；不同裝置需老師解除原裝置綁定。

記錄：完成活動才算通關。進度供課堂觀察，學號登入不等同正式身分驗證。

HTML 檔：沒有網路也能自由練習。跨裝置同步需要老師先設定課堂服務。

程式練習：本網頁是固定題目的輸出推演與互動練習，不是通用 Python 執行器。AI 工坊使用預先編寫的範例。

GitHub Pages：上傳 index.html 即可使用學習活動。老師可在「課堂連線設定」填入服務網址，並下載設定好的 HTML 供全班使用。
